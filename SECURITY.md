# Security Policy

## Reporting a vulnerability

Please do **not** report suspected security vulnerabilities through public Issues or Discussions.

Use the private support route listed on [writrex.com](https://writrex.com/) and include Security report in the subject. Provide a concise description, affected version, impact, and safe reproduction steps. Do not include active credentials or customer data.

We will acknowledge a valid report, investigate it privately, and coordinate disclosure once users can be protected.

## Scope
This policy applies to the released Writrex Plugin and its official purchase/support experience. Reports about third-party themes, plugins, hosting platforms or altered copies may need to be directed to the relevant maintainer.
