# Writrex Plugin FAQ

## What is this repository for?
This is the public community hub for Writrex Plugin: discussions, feedback, support guidance and the public roadmap. It does not distribute the plugin.

## Where can I purchase the plugin?
Visit [writrex.com](https://writrex.com/) for current product and purchase information.

## Where should I report a bug?
Use the **Bug report** issue form and include the plugin version, environment, expected result, actual result and reproduction steps.

## Where should I request a feature?
Use the **Feature request** issue form or start an Ideas discussion.

## Can I post my licence key or a private site URL?
No. Never post licence keys, passwords, tokens, customer information, backups, or private URLs in this public repository.

## How do I report a security issue?
Follow [SECURITY.md](SECURITY.md). Do not open a public issue or discussion for a potential vulnerability.
