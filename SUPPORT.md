# Support

Use the right place so we can help quickly and safely.

- Reproducible plugin problem: open a Bug report.
- Improvement idea: open a Feature request or Ideas discussion.
- General non-sensitive question: start a Discussion.
- Account, purchase or billing help: use the support contact on [writrex.com](https://writrex.com/).
- Security concern: follow [SECURITY.md](SECURITY.md) privately.

## For technical help
Include the Writrex Plugin version, WordPress and PHP versions where relevant, expected result, actual result, exact reproduction steps, and a redacted screenshot or error message if helpful.

Do not include credentials, licence keys, personal data, customer information, database exports, full server logs or private URLs.
