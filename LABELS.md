# Recommended labels

Create these labels in **Settings → Issues → Labels**.

| Label | Use |
| --- | --- |
| bug | Reproducible product problem |
| enhancement | Requested improvement |
| documentation | Public-docs change |
| question | Help or clarification needed |
| needs-triage | Maintainer review needed |
| needs-information | Reporter needs to clarify |
| duplicate | Already reported |
| security | Do not use publicly - direct reporter to private route |
| good-first-issue | Small, suitable community-doc task |
| planned | Accepted for future work |
| not-planned | Outside current direction |

Do not label security reports publicly with details. Move the conversation to the private route in [SECURITY.md](SECURITY.md).
