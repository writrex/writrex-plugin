# Contributing to the Writrex Plugin Community

Thank you for helping improve Writrex Plugin.

This repository is a community hub, not the plugin source repository. Do not submit plugin code, customer data, or copies of purchased files here.

## Helpful contributions
- Clear bug reports with reproduction steps
- Well-defined feature ideas
- Corrections or improvements to documentation
- Respectful answers to community questions

## Before posting
1. Search existing Issues and Discussions.
2. Use the relevant template or category.
3. Remove sensitive information.
4. Explain the user impact, not just the desired implementation.

All participation must follow the [Code of Conduct](CODE_OF_CONDUCT.md).
