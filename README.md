# Writrex Plugin Community

Welcome to the public community space for the **Writrex Plugin**.

This repository contains community information only. It does **not** contain plugin source code, release packages, licence keys, customer data, or private product implementation.

## Get started

- Visit [Writrex](https://writrex.com/) for product information and purchasing.
- Read the [FAQ](FAQ.md) for common questions.
- See the public [roadmap](ROADMAP.md).
- Start a non-sensitive conversation in **Discussions**.
- Use an Issue form for a reproducible bug, feature request, or documentation improvement.

## Get help safely

Please include the plugin version, platform or site context, expected result, and steps to reproduce when reporting a technical issue.

Never publish passwords, licence keys, access tokens, private URLs, customer information, backups, or security details. See [SUPPORT.md](SUPPORT.md) and [SECURITY.md](SECURITY.md).

## Community standards

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md). By posting here, you agree to keep discussions constructive, respectful and free of confidential information.

Thank you for helping improve Writrex Plugin.
